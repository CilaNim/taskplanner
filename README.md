Planner

A lightweight task management web app built with Spring Boot and PostgreSQL, featuring a clean frontend interface and a RESTful backend API.

Features
Task Management: Create, view, edit, and delete tasks.
Priority & Due Dates: Organize work with priorities (LOW, MEDIUM, HIGH) and deadlines.
Quick Status Toggle: Mark tasks as completed or active with a single click.
Filter Views: Easily switch between all, active, and completed tasks.
Input Validation: Backend validation with clean JSON error responses.
Built-in UI: Minimalist, responsive UI served directly by Spring Boot (no extra frontend server required).
Tech Stack
Java 21
Spring Boot (Spring MVC, Spring Data JPA, Hibernate, Validation)
PostgreSQL
HTML5 / CSS3 / Vanilla JavaScript
Maven
